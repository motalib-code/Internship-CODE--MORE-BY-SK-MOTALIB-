# Week 3 · Task 2 — Supervised Learning Algorithms

## Objectives
- Understand and implement three core supervised learning algorithms
- Compare Linear Regression, Logistic Regression, and Decision Trees

## Contents

| File | Description |
|------|-------------|
| `docs/supervised_learning_report.md` | Theoretical comparison of the three algorithms |
| `notebooks/supervised_learning_algorithms.ipynb` | Hands-on Jupyter notebook with code demos |
| `data/cleaned_titanic_data.csv` | Titanic dataset (from Task 1) used in Logistic Regression demo |

## Algorithms Covered

1. **Linear Regression** — Diabetes dataset (regression)
2. **Logistic Regression** — Titanic survival data (classification)
3. **Decision Tree Classifier** — Iris dataset (classification)
